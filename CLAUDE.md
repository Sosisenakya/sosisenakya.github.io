# Working in this repo

- The site lives in `Portofolio/` (plain HTML, CSS and JS, no build step). GitHub Pages serves it as-is.
- After every set of changes, commit and push to the working branch without asking first.
- At the end of every set of changes, make sure there is a pull request for the branch. Check for an existing one first and push to it rather than opening a duplicate.
- Merging stays with the owner.
